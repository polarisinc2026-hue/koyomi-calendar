「いつ始める？」「いつ山行く？」「この日だいじょうぶ？」が、いつものカレンダーでひと目でわかる無料の暦です。ボタンを押すだけで登録できます。

おかぴー暦（毎日）

毎日の六曜と、🌱⛰🙈のしるし。タップすると「その日に向いていること」も見られます。

🌱 はじめ日

新しいことを始めるのにいい日。天赦日・一粒万倍日なども入っています。

⛰ 山日和

暦の上で山に行くのにいい日と、毎月の休日のおすすめ。

🙈 あちゃー日

ちょっと気をつけたい日（不成就日・受死日・十死日）。大事な契約やスタートは別の日に。

うまく登録できないとき

PCのGoogleカレンダーで「他のカレンダー」の＋ →「URLで追加」を選び、下のURLを貼り付けてください。追加したあと、スマホのアプリにも自動で表示されます（反映まで少し時間がかかることがあります）。

🌱⛰の判定は、伝統的な暦注をもとにした「おかぴーオリジナル判定」です。山に行く日は天気予報をいちばんに。
