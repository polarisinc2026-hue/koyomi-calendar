毎日安心カレンダー

「いつ始める？」「いつ山行く？」「この日だいじょうぶ？」が、いつものカレンダーでひと目でわかる無料のカレンダーです。ボタンを押すだけで登録できます。

  • 暦
  • Chance!!
  • 登山日和⛰️
  • 慎重に

暦

毎日の六曜（大安・仏滅など）。タップすると、その日に向いていること・向いていないことがわかります。

Chance!!

新しいことを始めるのにいい日。天赦日・一粒万倍日など、昔から「始めるといい」とされる日です。

登山日和⛰️

暦の上で山に行くのにいい日と、毎月の休日のおすすめ。

慎重に

大事なことは避けたい日（不成就日・受死日・十死日）。契約やスタートは別の日にずらすと安心です。

暦（こよみ）ってなに？

昔の日本人が使っていた「日の天気予報」のようなものです。月の満ち欠けと太陽の動きから、その日が「何かを始めるのに向く日」か「控えめにしたほうがいい日」かを決めていました。

大安や仏滅もそのひとつで、今でも結婚式やお店のオープン、引っ越しの日取りに使われています。科学で運が変わるわけではありませんが、何百年も大事にされてきた縁起の目安です。

迷ったときに背中を押してくれる「きっかけ」として、気軽に使ってください。

うまく登録できないとき

PCのGoogleカレンダーで「他のカレンダー」の＋ →「URLで追加」を選び、下のURLを貼り付けてください。追加したあと、スマホのアプリにも自動で表示されます（反映まで少し時間がかかることがあります）。

「Chance!!」「登山日和」は、昔からの暦をもとにした毎日安心カレンダー独自の判定です。山に行く日は天気予報をいちばんに。
